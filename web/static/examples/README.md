# Module reference atlas

`module-reference-atlas.png` is original artwork generated with the built-in GPT imagegen tool for this workbench, using an imaginary unbranded cream overshirt. It contains a four-column, three-row atlas in this order: opening benefit, angles, lifestyle, texture, construction, steps, own-variant comparison, packaging, variant overview, FAQ, closing, and illustrative measurement table.

The direction uses a cream/sage campaign style lock, natural photographic scenes, a generic synthetic adult model, varied editorial composition and short Chinese captions. This is a static visual example only. Its garment, copy, accessories, colors and measurement values are never applied to a merchant's product. Image-grid previewing uses CSS positioning of the unchanged atlas, without paid generation or enlargement claims.

The final asset was copied into this project from the built-in generated output. No merchant upload or private photo was used as a reference. The original generation remains in Codex's generated_images directory.
