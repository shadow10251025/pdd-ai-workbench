# 租赁服务：部署与验收边界

独立服务端 API 入口为 `rental_server.create_env_app`。本轮没有公开部署、注册收费、调用真实生图接口或连接真实店铺。商家网站页面和本地助手的配对发布，应在本地真实样例验收后集成；本 API 不暴露桌面管理端或浏览器调试端口。

## 身份与存储

- 无公开注册、无默认管理员。首次用 `PDD_RENTAL_BOOTSTRAP_USER` / `PDD_RENTAL_BOOTSTRAP_PASSWORD` 建立平台管理员，密码至少12位，完成后移除引导变量。
- 平台管理员创建租户、设置图片请求/上架额度、停用租户；店主创建操作员和审核员、停用账号；审核员可读取和审核，不能启动生图或修改商品资料。
- 密码使用随机盐 PBKDF2；令牌和 CSRF 凭证仅存哈希。Cookie 为 Secure、HttpOnly、SameSite=Strict，Cookie 写请求需要 `X-PDD-CSRF`；API客户端可显式使用 Bearer。
- `/api/auth/devices` 查询设备会话；删除指定会话即时撤销。退出登录、账号或租户停用使后续请求失效。
- 每租户目录为 `PDD_RENTAL_ROOT/data/tenants/<服务器生成编号>`。草稿、图片、任务、额度和缓存隔离，接口不接受客户端指定的归属租户。
- API Key 仅在本次任务内存使用，任务/草稿/清单会递归移除密钥字段；刷新和恢复需要重新填写。不提供永久保存接口。

## 生产配置

安装 `requirements.lock.txt` 的已验证依赖，设置受保护业务目录 `PDD_RENTAL_ROOT` 和允许域名 `PDD_RENTAL_HOSTS`，再运行：

```sh
uvicorn rental_server:create_env_app --factory --host 127.0.0.1 --port 8001 --no-proxy-headers
```

使用TLS反向代理，只将实际代理IP加入 `PDD_RENTAL_TRUSTED_PROXY_IPS`，由代理覆盖 `X-Forwarded-Proto`。不得信任任意客户端转发头。外网只开放HTTPS，不开放8001、3000或9222等调试端口。生产请求缺少HTTPS会被拒绝。

当前执行器须单进程运行，每租户最多一项任务，进程最多两项。多机部署应先接入集中式队列和额度租约，不能直接增加uvicorn workers。`/health` 检查认证数据库。

## 接口与费用

`/api/auth/login|me|logout|devices` 管理会话；`/api/platform/tenants` 及其 `entitlement` 接口供平台管理员使用；`/api/tenant/users|usage` 管账号和配额；`/api/drafts` 保存商品包，草稿的 `review` 子接口记录人工审核。`/api/ai/*` 与本地工作台使用同一约定，始终隔离到当前租户。

图片任务先预留锁定上限，按已知请求次数结算；缓存与恢复批次不重复收费。取消只停止未发请求，扣费未知保留预留额度并阻止盲目重试。这里是应用请求配额，不是服务商确认的人民币账单。

当前不开放可由商户伪造成功的上架结算接口；站点上架额度预留给完成配对的本地助手。配对前不能向客户承诺在线自动上架已验收。桌面填表仅在回环管理端执行，最终发布由商家操作。后续助手应主动出站连接，使用短期授权和绑定店铺的签名任务，不能将CDP暴露给网站。

## 防护和发布门槛

图片/提示词API及下载共用安全HTTP客户端，检查全部DNS结果和跳转，连接固定到已校验IP。网站强制HTTPS并拒绝本机、内网与云元数据，本地演示开关不能放宽网站限制。上传流、像素、ZIP、响应体、并发、容量和磁盘余量均有限制。

公网启用前仍须验收实际域名/TLS/代理配置、商户API、服装/家居/数码三类实物图片、账单与备份恢复。客户端打包与混淆只能提高分析成本，不能保证绝对无法破解；权益与核心编排应由服务端控制。
