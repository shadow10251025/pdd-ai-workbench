# 旧授权服务的兼容说明

`server/main.py` 是旧的在线兑换码服务。当前桌面 `license.py` 使用离线 Ed25519 验签，不会因为放置 `license_server.txt` 就自动连接这里。旧桌面离线许可证不能被本服务即时吊销，两种协议不兼容。

出租版应采用项目根目录的 `rental_server.py`，由服务器检查账号、租户、权限、任务和额度。参见 [租赁服务部署边界](RENTAL_DEPLOYMENT.md)。旧协议仅用于兼容，不作为新网站权益主链路。

维护旧服务时，先设置至少12位的 `ADMIN_PASSWORD`，再运行 `deploy.sh`。脚本只监听回环地址，密码写入仅管理员可读的 `service.env`，不会输出密码。必须通过 HTTPS 代理远程访问。未配置有效密码时拒绝管理员登录。

`/admin/logout` 撤销本次令牌，`/admin/logout-all` 撤销全部后台会话。登录按来源地址限速，`/health` 检查数据库。这不是商户业务服务器，不应同时存放商户照片、生图密钥或签名私钥。
